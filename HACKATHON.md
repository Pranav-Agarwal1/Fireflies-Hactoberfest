## Problem
Problem 8: Build Anything with Gemma 4 - Local AI Innovation Challenge

We aim to make local Gemma fine-tuning accessible through a UI,
allowing users to fine-tune the model on public datasets and
generate responses tailored to their task using the fine-tuned model.


## Models

### Product
- Planned: Gemma 4 e2b or e4b for local fine-tuning and inference.
- Reason: To run the application's AI functionality locally within laptop hardware limits.

### Coding Assistants
- Planned: Gemma 12B for backend development and Gemma 4 e4b for UI development.
- Reason: To assist with backend and frontend implementation.
