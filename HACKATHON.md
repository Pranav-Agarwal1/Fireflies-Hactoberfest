## Problem
Problem 8: Build Anything with Gemma 4 - Local AI Innovation Challenge

## Proposed Project

A user interface and backend that help users fine-tune Gemma 4 for their task.
Users describe their task in a prompt and provide a public dataset, or use a
public dataset from Hugging Face selected according to their prompt. The
application will use the selected dataset to fine-tune the model through the
backend, with the workflow accessible from the user interface.

Only public data will be used, in accordance with the hackathon requirements.

## Selected Model and Justification

### Gemma 4

Gemma 4 is the intended model family for fine-tuning and is selected to align
with Problem 8. The goal is to adapt a model to the user's task using their
chosen public dataset, and make that process accessible through a user interface.

The exact checkpoint, model size, training framework, and hardware requirements
have not yet been selected. The team will verify checkpoint access, licensing,
and fine-tuning support before implementation and record the exact choices here.

## Implementation Status

The project is currently in the planning stage. Model integration and fine-tuning
are planned features; this document does not claim that they are already working.
